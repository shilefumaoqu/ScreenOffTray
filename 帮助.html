自动关屏 · ScreenOffTray 0.2.1

只关闭显示器，继续运行当前程序和后台任务。适用于 Windows 10 22H2 / Windows 11 x64，以及一个实体显示器。

开始使用

  1. 打开安装包，按 Windows 提示完成管理员确认。已有可用虚拟显示驱动会直接复用；日常使用不需要管理员权限。
  2. 安装完成后核对启动结果；需要配置时自动打开设置引导，升级且已就绪时直接进入托盘。点击“一键准备”，程序按当前实体屏的实际像素尺寸检查虚拟模式；横屏、竖屏和不同宽高比使用同一流程，不固定某个分辨率或缩放。
  3. Windows 已列出精确模式时直接复用，不改配置、不重载。缺少模式时，程序在普通权限允许的配置中保留原内容、备份原件并补充模式，必要时请求管理员确认，仅重新载入已核实的唯一虚拟设备。期间可能闪屏或改变布局；不卸载驱动、不关闭其他软件，也不会自动重启电脑。
  4. 设备重载后重新建立显示基线，再进入受保护准备，核对真实分辨率和缩放，完成后回到仅实体屏显示。显示“已就绪”后关闭设置，继续在托盘运行。准备期间请勿同时修改 Windows 显示设置。
  5. 驱动不接受模式、缩放不匹配、配置受保护、外部配置变更或设备要求重启时，会说明原因并保持关屏停用。分辨率已补充不代表缩放已匹配；设备重载前的旧快照不保证跨重载恢复。技术信息见“诊断详情”。
  6. 托盘右键是小菜单，“设置…”打开独立窗口；关闭窗口后继续在托盘运行。普通设置点保存生效，白名单增删即时保存。新用户默认空闲 10 分钟，识别到唯一旧设置时保留；开机启动默认关闭。

自动适配与异常处理

“自动适配显示”根据当前实体屏的源像素尺寸补充虚拟模式，竖屏不额外交换一次宽高。屏幕尺寸、方向或缩放变化后，旧匹配记录会失效，需要重新准备；后台不会擅自重载设备。

原有分辨率、全局刷新率和其他选项都会保留；全局刷新率也可能传播到新模式，不固定为某个刷新率。配置是 UTF-8 单监视器格式且普通权限可写时才能自动补充。受保护、归属不明或不支持的共享配置，需要由配置维护者补充精确模式；本工具没有提权写共享文件的接口。

首次准备和设置中的一键准备共用同一流程。管理员确认取消后，已安全补充的模式可能保留，但不会宣称设备已重载或关屏已启用。取消或退出会等待正在进行的系统设备操作返回，不强行结束系统进程。

每次点击“一键准备”都重新读取当前显示条件。临时扩展后，仅将已核实 MttVDD 的缩放匹配到实体屏；已一致时不重复写入。使用未公开的 Windows 缩放接口，须核对支持范围和实际读数，不支持自定义比例或无法核验时停止；不会修改实体屏缩放。失败后依照原恢复保护核对原布局，成功后回到仅实体屏显示。

若检测到配置同时被其他软件更新，会停止后续重载并保留原件、实际被替换版和变更记录，供核对处理；不会猜测性自动回滚。无法核验分辨率或缩放时同样保持停用，不降低实体屏分辨率。

设置窗口由独立 WPF 进程承载，分为通用、播放保护、关于三页，并提供浅色、暖白、黑色三种外观。浅色使用中性蓝灰雾面，不再照搬参考页的彩色几何壁纸；安装向导沿用同一套蓝灰材质、细高光边、玻璃卡片和双层月亮标识，同时保留系统原生文字、按钮、键盘操作与高 DPI 行为。窗口按工作区自动调整大小；文字保持正常排版，较小工作区以正文滚动保留操作按钮，长诊断与播放列表只在局部滚动。

关屏与唤醒

  • 默认快捷键为 Ctrl + Alt + F10，也可使用菜单“立即关屏”。托盘右键→“设置…”里点击快捷键输入框，直接按组合键录入，点击保存后生效并在下次启动时保留。“恢复默认”需再点击保存；取消不会修改。若组合键已被占用或保存失败，原快捷键保持有效。暂停自动关屏时，手动关屏仍可使用。
  • 实际关屏后有 3 秒保护期。期间的实体按键和鼠标按钮不唤醒，也不传给当前软件。
  • 保护期结束后，松开已按住的键，再按一次实体键盘或鼠标按钮唤醒。第一次按下及其松开只负责亮屏；第二次才正常操作软件。
  • 移动鼠标、滚轮、Windows 标记为注入的键鼠输入不唤醒。不能据此保证所有第三方内核模拟输入都可被区分。
  • 关屏期间保持系统运行，不锁屏、不睡眠、不休眠、不关机。工具不修改电源计划、NVIDIA 模式或安全设置。

自动关屏与暂停原因

自动计时只使用已有实体键鼠识别规则。打开设置，在“当前播放程序”旁加入白名单；保存的名单用单行下拉选择，可直接移除。添加和移除即时保存，取消其他设置不会撤销名单变化。首次使用名单为空；只有可执行文件完整路径匹配的音频程序正在播放，才保护自动关屏。纯静音视频、名单以外的程序和系统亮屏请求本身不保护。

播放停止后重新等待完整关闭时间。默认播放保护上限为60分钟，从最后一次实体输入计算；达到上限后即使继续播放，也不再保护自动关屏，但仍须达到普通空闲时间。可在设置关闭上限。可靠对应到同一程序、状态新鲜且明确暂停的播放器会从当前播放中排除；不保证所有播放器的识别。音频状态或白名单读取失败时，自动关屏暂停并显示原因；损坏的名单不会当作空名单，原始设置保留，成功保存有效名单后恢复判断。手动“立即关屏”和快捷键不受播放保护限制。

安装、升级与卸载

升级或卸载前，请先在托盘正常退出。安装器不会强制结束正在运行的托盘程序。卸载保留个人设置；复用其他安装已存在的驱动设备不会被本产品删除。系统需要重启时会提示，由你决定何时重启。

程序位于 Program Files；日志和恢复快照位于 %LOCALAPPDATA%\ScreenOffTray\运行记录。请勿在关屏过程中手动删除快照。安装包完全离线；首版应用尚未购买代码签名证书，Windows 可能显示未知发布者，驱动文件保留原始签名。

更新

托盘菜单保持精简。打开“设置…”后，可在合并设置中查看当前版本、开启或关闭自动检查，并手动检查更新。自动检查默认开启，每次启动检查一次，只在发现新版时通知。取消勾选并保存后，自动检查停止；手动检查仍可用。发现新版时提供下载入口；程序不会自动安装更新或结束自己。

更新源为 shilefumaoqu/ScreenOffTray 的 GitHub Releases。自动检查默认开启，只读取稳定版本；发现新版时提示并提供下载入口，不会自动安装或结束程序。旧版本 Release 和安装包保持独立。

显示或显卡疑问

混合显卡电脑的实体屏由集成显卡输出，并不等于独立显卡无法渲染。虚拟屏对自动独显直连切换的影响仍未验证。需要游戏或独显直连时，先从托盘退出，并在 Windows 显示设置核对虚拟屏已断开。

显示条件不符时，程序暂停关屏。安装后会直接进入独立首次配置引导，检查通过才显示“已就绪，开始使用”。显示条件不符时，引导会说明如何处理，并留在同一窗口供重新检查；关闭可稍后处理。首次配置未完成时，程序不会关屏。正常就绪启动保持安静。同一次运行的相同未解决异常不反复弹窗，可随时从托盘“设置…”查看。发生恢复失败时请保留运行记录，并使用旧版回退材料，避免盲目重装其他软件的显示驱动。

ScreenOffTray Help

Turns off the display while applications and background tasks continue. Version 0.2.1 targets Windows 10 22H2 / Windows 11 x64 with one physical display.

Get started

After installation, choose “Complete setup” or “Adapt display”. The same flow uses the current physical source pixel dimensions for landscape, portrait and different aspect ratios. If Windows already lists the exact virtual mode, no configuration or device reload is needed. Otherwise, the app preserves and backs up a supported, writable configuration, adds the mode, then requests administrator approval only for restarting the verified virtual device. This may flicker or change the display layout; it does not uninstall drivers, close other apps or reboot Windows automatically.

After reload, setup captures a fresh display baseline and runs the existing protected resolution and DPI checks. Only then does it leave physical display only and report Ready. Do not change Windows display settings during preparation. A mode entry alone does not prove matching DPI; failure leaves display off disabled. A pre-reload snapshot is not guaranteed to restore a reloaded device's changed identities.

The default timeout is 10 minutes. A single identifiable previous timeout is preserved; conflicting values require your choice. Start with Windows is off by default. Timeout, shortcut, language and startup options are combined in Settings.

Automatic mode adaptation

Both setup entry points derive virtual modes from the live physical source dimensions. Portrait dimensions are not swapped twice. A change in physical size, rotation or DPI invalidates old matching evidence; the app does not silently restart devices in the background.

Existing modes, global refresh rates and all other settings are retained. Global rates may also apply to new modes. Automatic append supports ordinary-permission writable UTF-8, single-monitor configurations. Protected, ambiguous or unsupported shared configurations stop with instructions for their maintainer; there is no elevated shared-file writer.

Cancelling the administrator prompt may leave a safely added mode in the file, but does not claim a successful reload or readiness. Cancellation and exit wait for an in-flight system operation rather than force-killing it. Conflicting external edits stop further reload and retain the original, actual replaced version and change record for resolution; no speculative automatic rollback is performed.

Every Prepare attempt reads current display conditions. After a guarded temporary extension, only the verified MttVDD scale is matched to the physical display; matching values are not rewritten. This uses an undocumented Windows scaling interface with range and measured-readback checks. Unsupported custom scales or unverifiable readings stop preparation without changing physical scale. Failures retain the existing original-layout recovery protection; successful preparation leaves physical display only.

Unsupported modes, unavailable or mismatched DPI, configuration conflicts and reboot requirements are reported. The app does not lower physical resolution.

Settings runs in a separate WPF process with General, Playback protection and About pages. Light, Warm white and Black appearances are available. Light uses a neutral blue-gray frosted background rather than the reference sample's colored geometry wallpaper. Setup uses the same blue-gray material, fine highlight edges, glass cards and layered-moon mark while retaining native text, buttons, keyboard behavior and high-DPI handling. The window adapts to the monitor work area; text keeps normal layout, smaller work areas allow body scrolling while preserving action buttons, and diagnostics and playback lists use local scrolling.

Turn off and wake

The default shortcut is Ctrl+Alt+F10. Open Settings from the tray, focus the shortcut box and press the desired combination. Release the keys, then Save to apply and remember it. “Use default” changes the draft until saved; Cancel keeps the current shortcut. If the shortcut is already in use or saving fails, the previous shortcut stays active. You can also use “Turn off now”. Manual off still works while automatic off is paused. The 3-second guard starts after the display turns off. Presses during the guard are ignored. Release any held input, then press a physical key or mouse button to wake. The first press and release are consumed; the second works normally. Mouse motion, scrolling and Windows-marked injected input do not wake. Some kernel-level simulated input cannot be reliably distinguished.

The app does not lock, sleep, hibernate or shut down Windows. It does not change NVIDIA modes, power plans or security settings.

Automatic off and pause reasons

The timer retains the existing physical-input classification. In Settings, add a current audio program to the whitelist. The saved list uses a single-row dropdown with Remove. Add/remove saves immediately; Cancel does not undo these list changes. New installs start with an empty list. Only audio from a matching full executable path protects automatic off. Silent video, unlisted apps and system display requests alone do not protect it.

A full idle interval restarts when playback protection ends. The default cap is 60 minutes since the last physical input. At the cap, playback no longer blocks off; the normal idle interval must also be reached. The cap can be disabled. Fresh, explicitly paused player states suppress a source only when reliably matched to that program. Not every player can be identified. Unavailable audio or whitelist state pauses automatic off and shows why. A damaged whitelist is preserved rather than treated as empty; saving a valid list restores normal judgment. Manual off and the hotkey bypass playback protection.

Upgrade and uninstall

Exit normally from the tray first. Setup does not force-close the app. Uninstall retains user settings and never removes a reused device belonging to another installation. Restart prompts are explicit and do not automatically restart Windows.

Runtime files are stored at %LOCALAPPDATA%\ScreenOffTray\运行记录. Do not delete recovery snapshots during an active session. This offline installer contains the original signed virtual display driver. The application itself currently has no purchased code-signing certificate.

Updates

To keep the tray menu compact, update controls are in the combined Settings window. It shows the current version and offers “Check for updates” and a download link. Automatic checking is on by default and runs once at startup; it notifies only when a newer version is found. Turning it off and saving stops automatic checks, while manual checking remains available. The app offers a download entry and never installs an update or exits automatically.

The update source is the stable GitHub Releases feed for shilefumaoqu/ScreenOffTray. Automatic checks are on by default; a newer release only produces a notification and download entry. The app never installs an update or exits automatically. Older releases remain available.

Compatibility boundary

Virtual display effects on automatic discrete-GPU display switching remain unverified. An integrated-GPU output route alone does not show that the discrete GPU has stopped rendering. Review Windows display settings before workflows that require direct discrete-GPU output. Ready startup stays silent. A confirmed unready startup opens the focused setup guide with the cause and next steps. The same unresolved issue does not repeatedly reopen the window during that run. Open Settings from the tray to review display preparation at any time.

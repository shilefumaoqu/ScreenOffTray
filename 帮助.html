自动关屏 · ScreenOffTray 0.1.4

只关闭显示器，继续运行当前程序和后台任务。适用于 Windows 10 22H2 / Windows 11 x64，以及一个实体显示器。

开始使用

  1. 打开安装包，按 Windows 提示完成管理员确认。已有可用虚拟显示驱动会直接复用；日常使用不需要管理员权限。
  2. 首次使用时点击“自动准备并启用关屏”。程序会读取真实屏幕的分辨率和缩放，尝试自动匹配虚拟屏，再回到仅真实屏幕输出。准备时屏幕可能闪动，真实屏幕保持显示，正在运行的程序会继续。成功后自动完成，不必手动切换显示模式。准备期间请勿同时在 Windows 中修改显示设置。
  3. 若现有驱动不支持所需模式或无法安全匹配，准备会停止并恢复原布局，关屏保持暂停。程序不会修改现有驱动或降低真实屏幕分辨率；技术信息在“诊断详情”中查看。
  4. 托盘右键→“设置…”中调整空闲分钟数、快捷键、语言和开机启动；新用户默认为 10 分钟，识别到唯一有效旧设置时保留旧值。开机启动默认关闭。

关屏与唤醒

  • 默认快捷键为 Ctrl + Alt + F10，也可使用菜单“立即关屏”。托盘右键→“设置…”里点击快捷键输入框，直接按组合键录入，点击保存后生效并在下次启动时保留。“恢复默认”需再点击保存；取消不会修改。若组合键已被占用或保存失败，原快捷键保持有效。暂停自动关屏时，手动关屏仍可使用。
  • 实际关屏后有 3 秒保护期。期间的实体按键和鼠标按钮不唤醒，也不传给当前软件。
  • 保护期结束后，松开已按住的键，再按一次实体键盘或鼠标按钮唤醒。第一次按下及其松开只负责亮屏；第二次才正常操作软件。
  • 移动鼠标、滚轮、Windows 标记为注入的键鼠输入不唤醒。不能据此保证所有第三方内核模拟输入都可被区分。
  • 关屏期间保持系统运行，不锁屏、不睡眠、不休眠、不关机。工具不修改电源计划、NVIDIA 模式或安全设置。

自动关屏与暂停原因

自动计时只记录沿用现有识别规则的实体键鼠活动，Windows 标记为注入的模拟输入不重置计时。应用请求保持亮屏（视频、演示等）时自动暂停，托盘显示暂停原因；请求解除后重新等待完整关闭时间。手动“立即关屏”和快捷键仍可使用。普通后台计算和仅要求系统继续运行的请求不阻挡自动关屏。

系统亮屏请求不能证明正在播放视频：个别音乐应用也可能保留此请求。为避免误关视频，程序不会按应用名称擅自忽略。此时请根据托盘状态核对播放器；本程序不关闭其他程序、不撤销它们的请求。部分未标记的内核虚拟输入仍不在实体识别保证范围。

安装、升级与卸载

升级或卸载前，请先在托盘正常退出。安装器不会强制结束正在运行的托盘程序。卸载保留个人设置；复用其他安装已存在的驱动设备不会被本产品删除。系统需要重启时会提示，由你决定何时重启。

程序位于 Program Files；日志和恢复快照位于 %LOCALAPPDATA%\ScreenOffTray\运行记录。请勿在关屏过程中手动删除快照。安装包完全离线；首版应用尚未购买代码签名证书，Windows 可能显示未知发布者，驱动文件保留原始签名。

更新

托盘菜单保持精简。打开“设置…”后，可在合并设置中查看当前版本、开启或关闭自动检查，并手动检查更新。自动检查默认开启，每次启动检查一次，只在发现新版时通知。取消勾选并保存后，自动检查停止；手动检查仍可用。发现新版时提供下载入口；程序不会自动安装更新或结束自己。

当前尚未配置 GitHub 更新源。没有更新源时程序不会发出请求，手动检查会提示“更新源未配置”，不会显示“已是最新”。仓库配置为 owner/repo 后，检查来源为对应 GitHub Releases latest。

显示或显卡疑问

混合显卡电脑的实体屏由集成显卡输出，并不等于独立显卡无法渲染。虚拟屏对自动独显直连切换的影响仍未验证。需要游戏或独显直连时，先从托盘退出，并在 Windows 显示设置核对虚拟屏已断开。

显示条件不符时，程序暂停关屏。首次引导只显示一次，正常启动和后台自检不弹准备窗口。同一异常只提示一次，可从托盘“设置…”进入准备区处理。发生恢复失败时请保留运行记录，并使用旧版回退材料，避免盲目重装其他软件的显示驱动。

ScreenOffTray Help

Turns off the display while applications and background tasks continue. Version 0.1.4 targets Windows 10 22H2 / Windows 11 x64 with one physical display.

Get started

Complete the Windows administrator prompt. An existing usable virtual display driver is reused. On first use, choose “Prepare and enable display off”. The app reads your real display, tries to match the virtual display, then leaves only your real display active. Your real screen stays on and your apps keep running. Do not change Windows display settings during preparation. Success completes automatically without a second Finish step. If the supported mode or scaling cannot be safely matched, setup stops, restores the original layout and leaves display off paused. It does not alter an existing driver or reduce the real display's resolution. Open “Diagnostic details” for technical information.

The default timeout is 10 minutes. A single identifiable previous timeout is preserved; conflicting values require your choice. Start with Windows is off by default. Timeout, shortcut, language and startup options are combined in Settings.

Turn off and wake

The default shortcut is Ctrl+Alt+F10. Open Settings from the tray, focus the shortcut box and press the desired combination. Release the keys, then Save to apply and remember it. “Use default” changes the draft until saved; Cancel keeps the current shortcut. If the shortcut is already in use or saving fails, the previous shortcut stays active. You can also use “Turn off now”. Manual off still works while automatic off is paused. The 3-second guard starts after the display turns off. Presses during the guard are ignored. Release any held input, then press a physical key or mouse button to wake. The first press and release are consumed; the second works normally. Mouse motion, scrolling and Windows-marked injected input do not wake. Some kernel-level simulated input cannot be reliably distinguished.

The app does not lock, sleep, hibernate or shut down Windows. It does not change NVIDIA modes, power plans or security settings.

Automatic off and pause reasons

The automatic countdown uses the existing physical-input classification. Windows-marked injected input does not reset it. A display-required request (for video, presentations, or other apps) pauses automatic off, and the tray shows why. A full timeout starts when the request ends. Manual off and the hotkey remain available. System/execution keep-alive requests alone do not block automatic off.

A display request does not prove video playback: a music app can retain one too. The app keeps this protection rather than ignoring an application by name. It never closes other apps or clears their requests. Unmarked kernel-level virtual input remains outside the classification guarantee.

Upgrade and uninstall

Exit normally from the tray first. Setup does not force-close the app. Uninstall retains user settings and never removes a reused device belonging to another installation. Restart prompts are explicit and do not automatically restart Windows.

Runtime files are stored at %LOCALAPPDATA%\ScreenOffTray\运行记录. Do not delete recovery snapshots during an active session. This offline installer contains the original signed virtual display driver. The application itself currently has no purchased code-signing certificate.

Updates

To keep the tray menu compact, update controls are in the combined Settings window. It shows the current version and offers “Check for updates” and a download link. Automatic checking is on by default and runs once at startup; it notifies only when a newer version is found. Turning it off and saving stops automatic checks, while manual checking remains available. The app offers a download entry and never installs an update or exits automatically.

No GitHub update source is configured yet. With no source, the app makes no request; a manual check says the update source is not configured and does not claim the app is up to date. Once configured as owner/repo, checks use that repository's GitHub Releases latest.

Compatibility boundary

Virtual display effects on automatic discrete-GPU display switching remain unverified. An integrated-GPU output route alone does not show that the discrete GPU has stopped rendering. Review Windows display settings before workflows that require direct discrete-GPU output. Normal startup and background checks stay silent. The introduction is shown once; identical unresolved issues do not repeat notifications. Open Settings from the tray to review display preparation.

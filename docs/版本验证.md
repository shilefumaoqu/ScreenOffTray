# 0.2.2 验证范围 / Validation scope

本版只修复源码重新打包兼容性。程序运行逻辑、设置外观、驱动、显示准备、关屏、输入恢复和播放保护沿用 `0.2.1`。完整记录见 [0.2.2 构建兼容修复](0.2.2-构建兼容修复.md)。

## 已完成

- Windows PowerShell 5.1 / ANSI 936 的实际工程读取与图标路径检查通过。
- 本地依赖加载夹具验证二进制请求头、冷缓存解压、缓存复用和错误哈希阻断。
- 默认根入口在干净源码副本及全新依赖缓存下下载三项依赖，构建三个工程并核对最终 14 个产品文件。
- innounp 固定到 GitHub 附件 ID `695694723`、版本 2.71.3 和 SHA256 `F8E45C9676BEBC7D7570108AB572673B541FCF7A7D3D24A04319AC6B5315B4E8`。
- 版本一致性、更新解析、安装器版本门禁和安装包解包检查。

## 未验证

- 未在本机覆盖安装正式程序。
- 未在另一台全新 Windows 电脑上实际安装；全新依赖缓存构建发生在当前 Windows 环境的隔离目录。
- 未重复端到端人工关屏、驱动和输入恢复矩阵，因为相关运行代码未修改。
- 应用和安装器没有购买代码签名证书。

## English

This release fixes source-build compatibility only. Runtime behavior, Settings appearance, drivers, display preparation, display-off, input recovery and playback protection are unchanged from `0.2.1`.

The actual project loader and icon paths pass under Windows PowerShell 5.1 with ANSI code page 936. A local fixture passed binary request-header, cold extraction, cache reuse and corrupt-hash rejection checks. The default root entry used a clean source copy and fresh dependency cache to download all three dependencies, build all projects and verify 14 extracted product files. innounp is pinned to GitHub asset ID `695694723`, version 2.71.3 and SHA256 `F8E45C9676BEBC7D7570108AB572673B541FCF7A7D3D24A04319AC6B5315B4E8`.

The installed application is not overwritten. A second clean Windows computer was not used; the fresh-cache build ran in an isolated directory on the current Windows machine. Hardware display-off, driver and input-recovery matrices were not repeated because runtime code did not change. The application and installer remain unsigned.

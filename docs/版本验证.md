# 0.2.7 验证范围 / Validation scope

0.2.7 使用 Rust 读取 Windows 播放器会话。原有 5 秒轮询、保护和降级规则保持。独立运行五分钟，28 个私有驻留样本全部低于 20,000,000 字节，峰值 19,161,088 字节。测试使用与安装包相同的 DLL，读取真实播放中会话 61 次。播放、暂停残留音频、恢复和停止通过契约检查。受控播放器未能在私有桌面发布可辨认的会话，真实切换过程尚待验证。

空工具缓存运行默认打包入口，核对了 16 个安装文件和 11 个回退文件。三个驱动文件哈希无变化。回退包只替换程序和支持文件。真实安装、设置保留、回退和已安装后台的内存尚待验证。

The packaged Rust reader passed a five-minute isolated run with 28 samples under 20,000,000 bytes of private resident memory. The peak was 19,161,088 bytes. The default build entry worked from an empty tool cache. The installer and rollback payloads contained 16 and 11 files respectively. Playback transition contracts passed. Live playback transitions, an actual upgrade or rollback, and installed background memory remain unverified.

# 0.2.6 验证范围 / Validation scope

本版新增应用内下载及保存后重启更新，沿用现有升级安装器、设置事务、正常显示恢复/退出和启动确认。程序和安装器文件版本为 0.2.6.0，AssemblyVersion 保持 0.0.0.0。原生玻璃、主题与显示/音频业务算法未改，先前的[玻璃实拍](原生玻璃验证.md)继续适用于未改动的材质。

- 54 项下载与信任边界隔离检查：官方资产元数据、缺少/错误 digest、大小上下界、截短/损坏文件、HTTP 故障、恶意重定向、重定向上限、取消、资源释放及本轮缓存清理。
- 11 项实际更新控制器检查：无安装包、显示/保存忙状态、重复提交、保存失败、辅助进程拒绝、等待后状态改变，以及提交先于正常退出。平台、设置与安装协作者为假实现。
- 89 项中英文 WPF 布局检查；真实 UI Program 与命名管道在两种语言下走通“下载→取消→重试→保存草稿并提交更新”，安装端为假后台。普通设置保存及关闭也通过。
- 58 项现有请求/状态/设置契约、12 项启动确认、12 项设置管道用例；32 项版本/安装包解析及 11 项安装数值门禁，公开版本一致性、工程输入检查。
- 实际官方 0.2.5 安装包下载、长度、SHA256 和文件版本校验通过，副本随后删除，没有执行安装器。发布后针对 0.2.6 的公开下载与版本发现另行回验。
- 更新实现经过专门代码审查，两处缓存失效与退出超时恢复问题已修复，定向复核及 0.2.6 发布差异审查无未解决 P1/P2。
- Inno Setup 7.1.0 干净构建并解包，核对 14 个产品文件、临时核验助手、三个 EXE 的 0.2.6.0 文件版本、0.0.0.0 AssemblyVersion 及固定驱动哈希；没有日志、个人配置、测试程序或 PDB。最终解出的设置 EXE 在假后台、私有非输入桌面三次呈现并正常退出。

安装器的 `/UPDATEONLY=1` 分支拒绝首次安装、首次安装续跑及回退路径；源码门禁检查不能代替真实安装。程序不会强杀当前产品或其他软件，不会通过更新入口安装驱动或自动重启 Windows。安全退出超时后保留材料，提示等待托盘退出后从开始菜单重开重试；没有延迟自动安装。

## 未验证与使用边界

未覆盖安装本机正式程序。真实 UAC 取消、安装器替换文件、超时提示的实际交互及安装后正式运行未计作通过。隔离测试没有注册输入钩子或执行显示 APPLY，不能代替完整升级和实机关屏验收。应用和安装器未代码签名。

深色双背景、真实跨 DPI 拖动、Windows 10 材质回退及长期资源观察复用既有边界，未追加实机验收。私有桌面离屏截图只用于布局，不能充当原生玻璃实拍。本版没有重新承诺后台低于 20 MB。

从 0.2.5 及更早版本获得此更新器，需要先手动安装一次 0.2.6。发布 Release 不代表本机已经升级。

## English

Version 0.2.6 adds verified in-app downloads and an explicit save-and-restart handoff to the existing installer. File versions are 0.2.6.0; AssemblyVersion stays 0.0.0.0. Glass, themes and display/audio algorithms are unchanged.

Validation includes 54 downloader/boundary checks, 11 production-controller checks with fake collaborators, 89 bilingual WPF layout checks, bilingual real-UI command exchange, 58 existing coordination/settings contracts, 12 startup checks, 12 pipe checks, 32 update-parser cases and 11 installer version gates. An actual official 0.2.5 package was downloaded and verified without execution. Implementation, recovery and release-delta reviews found no unresolved P1/P2. The Inno Setup 7.1.0 package was built from clean sources and extracted: 14 product files, the temporary verifier, all three EXE versions, stable AssemblyVersion and pinned drivers matched, without personal configuration, logs, tests or PDBs. The extracted Settings EXE presented and exited normally three times with a fake backend on a private non-input desktop. Public 0.2.6 download verification is recorded separately.

No host upgrade was performed. Real UAC cancellation, file replacement, timeout-dialog interaction and post-install product operation remain unverified. Isolated tests do not establish real-hardware acceptance or a sub-20 MB background result. The app and installer are unsigned. Older versions require one manual installation of 0.2.6 to gain the updater; a Release is distinct from the installed version.

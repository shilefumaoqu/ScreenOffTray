# 0.1.9 验证范围 / Validation scope

本版为预发布，以下是已完成检查和剩余边界，不是全面稳定性保证。

## 已完成

- C稿结构、宽窄窗口、中英文代表样本、分钟/快捷键校验、保存取消、名单即时保存与失败保留、准备取消的隔离检查。
- 低高度错误展示及恢复29项、中文96/192模拟DPI各29项、英文原窗口宽窄29项定向检查通过。真实窗口DPI120；其他DPI/工作区为模拟输入，不冒充实屏切换。
- 四类猫动作、随机队列、键盘路由、姿态绘制、隐藏/最小化停止和重复释放的隔离检查。
- 专门codex review使用gpt-6.1-sol/high，发现的低高度与旧测试入口问题已处理，后续最小增量独立复核。
- 当前未插桩源码的可见关闭与宿主消息循环存活检查通过；无真实设置/设备操作。
- .NET Framework 4.8/C#5、Inno Setup 7.1.0干净暂存构建，最终包解包比对。11项产品文件，无日志、个人设置、快照、测试程序或PDB；AssemblyVersion保持0.0.0.0，FileVersion=0.1.9.0。
- 驱动INF/DLL/CAT和UI接入前的39项冻结文件保持不变。未改系统显示、驱动、安全或电源设置。

## 已知问题与未验证

可见关闭探针曾在FormClosed后超时；旧诊断二进制、带记录副本与当前源码随后都正常关闭并继续宿主消息循环，原因仍未定位。没有为迎合测试猜测修改退出语义，也没有宣称偶发超时已根治。

本版未验证干净Windows安装/升级、长期运行、真实跨屏DPI切换或全部硬件。未重复人工关屏矩阵。虚拟屏可能影响部分混合显卡的自动独显直连，未验证全面无影响。首次准备仅支持一个已启用实体屏；远程虚拟屏条件不符时可稍后处理，无需重复安装。

截图是实际WinForms设置窗口，来自隔离假数据，并非用户当前配置；测试源码可复现部分检查。发布安装包与已验证的本地产物逐字节比对，公开发布不等于实机安装成功。

## English

Targeted native UI, animation, settings transaction and cancellation checks passed in isolation. Representative simulated DPI/work areas were tested; actual HWND DPI was120. Dedicated code review used gpt-6.1-sol/high. The final installer was unpacked and compared to the clean payload; driver files and accepted core decisions were preserved.

A visible close probe previously timed out after FormClosed. Subsequent old-binary and current-source checks completed closure while the host loop survived; the cause is unknown. This is not a claim of permanent resolution.

Clean Windows installation/upgrades, long-running behavior, physical DPI transitions and full hardware compatibility remain unverified for this release. Remote virtual-display preparation and multiple physical displays are not supported. Hybrid GPU switching compatibility remains uncertain. The screenshot uses isolated demo data.

# 0.2.5 验证范围 / Validation scope

0.2.5 修正版本号冲突：本地已运行 0.2.4 时，不能把后发布的同号包当作更新。本版提升文件、UI、安装器和 Release 版本，保留 0.2.4 及历史材料，不覆盖发布。相对已审查的 0.2.4，玻璃、更新解析和业务运行逻辑不变；29 项更新检查（含 0.2.4→0.2.5）及 9 项安装门禁通过。以下玻璃实拍和生命周期证据复用 0.2.4 的未变实现，当前构建与最终包另行核对。

设置窗口接入真实 Windows Desktop Acrylic，替代未通过双背景验收的近实色表面。与 Pane 的自定义合成参数有平台差异，实拍见[原生玻璃验证](原生玻璃验证.md)。

- .NET Framework 4.8 / C# 5 三工程构建；79 项中英文隔离检查通过。
- 同一浅色窗口在外部蓝、橙背景实拍，色调改变、背景柔化、前景文字清晰；真实 UI 使用假后台，无关屏或正式设置写入。
- 三次隔离设置进程启动、呈现与正常关闭通过。
- 29 项更新解析/安装包资产检查、9 项升级版本门禁、公开版本一致性及工程输入检查通过。
- 专门审查与 DPI 裁切、捕获失败状态定向复核完成，无未解决 P1/P2。
- Inno Setup 7.1.0 干净构建后解包，核对 14 个产品文件、临时核验助手、文件版本与固定驱动哈希，无 PDB、日志、个人配置、快照或测试程序。

未覆盖安装本机正式程序。新装、真实提权取消及安装后正式运行不计作通过。深色双背景、真实跨 DPI 拖动、Windows 10 回退呈现及长期资源观察未实机复验；DPI 检查模拟消息顺序，没有改变系统缩放。应用和安装器尚未代码签名。

驱动、显示准备、关屏、输入恢复、播放保护及快捷键运行逻辑未改，既有人工矩阵未重复。发布后的真实 GitHub 更新与公开下载回验单独记录，假 HTTP 解析测试不代替它。

## English

Settings uses native Desktop Acrylic instead of the near-opaque surface that failed the glass test. The same Light window was photographed across separate blue/orange desktop backgrounds: tint changes, underlying detail softens and foreground text stays clear. This adapts Pane's style rather than copying every compositor parameter.

Version 0.2.5 corrects the same-version collision so an existing 0.2.4 installation can discover the newer package. Glass and runtime logic are unchanged. Twenty-nine update parser/asset cases and nine installer version cases passed. The existing glass photographs and three UI lifecycle results are reused for unchanged code. Dedicated review, the current build, UI checks and final extraction are recorded separately; there is no automatic installation.

This build was not installed over the existing application. Dark dual-background, live cross-DPI, Windows 10 fallback presentation, long-run resources and real installation remain unverified. Display/input/audio logic is unchanged, so existing hardware matrices were not repeated. The app and installer remain unsigned. Live update/download checks are separate from fake-HTTP parser tests.

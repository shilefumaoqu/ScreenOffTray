# 0.2.3 验证范围 / Validation scope

本版修复设置窗口的更新下载动作和 Pane 主题映射。驱动、显示准备、关屏、输入恢复、播放保护、快捷键和用户数据格式保持不变。实现与设计采用记录见 [设置主题与更新动作修复](设置主题与更新动作修复.md)。

## 已完成

- 主程序和独立 WPF 设置程序使用 .NET Framework 4.8 / C# 5 编译通过。
- 中英文私有非输入桌面 WPF 检查 55 项通过，覆盖跟随系统／浅色／深色、系统主题解析、浅深颜色差异、旧主题迁移和更新按钮文案。
- 更新解析与下载资产检查 22 项通过，覆盖 `0.2.2 → 0.2.3`、精确 Setup 名称、大小写精确的 Release Tag、仓库 URL 校验和不可信 URL 拒绝。
- 命名管道检查 12 项通过；首次沙箱运行遇到子进程连接超时，提升到正常 Windows 环境后完整通过。
- 版本一致性、安装器版本门禁、仓库结构和 Windows PowerShell 5.1 构建编码检查通过。
- 最终 Inno Setup 7.1.0 安装包从干净暂存目录构建，并解包核对产品文件、三个驱动哈希和公开下载字节。

## 未验证

- 未在本机覆盖安装正式程序；当前 Program Files 仍保留旧版。
- 自动化检查没有真正启动浏览器；验证的是按钮文案、后端动作接线和安装包资产 URL 解析。
- 未覆盖 Windows 主题运行中切换事件；窗口应用新状态或重新打开时会重新读取系统主题。
- 未重复人工关屏、驱动和输入恢复矩阵，因为相关运行代码未修改。
- 应用和安装器没有购买代码签名证书。

## English

Version 0.2.3 fixes the Settings update-download action and Pane theme mapping. Drivers, display preparation, display-off, input recovery, playback protection, hotkeys and user-data formats are unchanged.

The main app and separate WPF Settings app build on .NET Framework 4.8 / C# 5. Fifty-five isolated Chinese and English WPF checks cover System / Light / Dark, system-theme resolution, distinct light/dark colors, legacy theme migration and update button labels. Twenty-two update parser and installer-asset checks cover `0.2.2 → 0.2.3`, exact Setup naming, case-sensitive release tags, repository URL validation and rejection of untrusted URLs. Twelve named-pipe checks passed; an initial sandbox connection timeout passed under the normal Windows environment. Release consistency, installer gating, repository layout and Windows PowerShell 5.1 build encoding passed. The final Inno Setup 7.1.0 package was built from a clean stage and verified after extraction, including driver hashes and public-download bytes.

The installed application was not overwritten. Automated checks did not launch a browser; they verified the button state, backend action wiring and installer asset parsing. A live Windows theme-change event is not wired; applying new state or reopening Settings re-reads the system theme. Hardware display-off, driver and input-recovery matrices were not repeated because runtime code did not change. The application and installer remain unsigned.

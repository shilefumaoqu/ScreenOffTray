# 0.2.4 验证范围 / Validation scope

本版按 `suming-ui-reference` 的 Pane 参考包 `0.1.1` 重新校准设置窗口玻璃材质，并完成实际桌面浅色、深色对照。驱动、显示准备、关屏、输入恢复、播放保护、快捷键和用户数据格式保持不变。实现与设计采用记录见 [设置主题与更新动作修复](设置主题与更新动作修复.md)。

## 已完成

- 主程序和独立 WPF 设置程序使用 .NET Framework 4.8 / C# 5 编译通过。
- 中英文私有非输入桌面 WPF 检查 67 项通过，覆盖跟随系统／浅色／深色、Pane 控件填充与四段高光边、可读性表面回退、旧主题迁移、固定底栏、窄窗、更新按钮和彩色壁纸移除。
- 在真实 Windows 桌面以当前 DPI 打开同一 WPF 源码进行浅色、深色实拍；对照 Pane 固定授权截图，确认中性蓝灰层、轻卡片、按钮、开关、分段选择和雾蓝强调色一致。WPF 无 Pane 的 HostBackdrop，故以约 98% 可读性表面和边缘高光作为平台回退，不能称为原生逐像素一致。
- 更新解析与下载资产检查 25 项通过，覆盖 `0.2.3 → 0.2.4`、精确 Setup 名称、大小写精确的 Release Tag、仓库 URL 校验和不可信 URL 拒绝。
- 安装器升级版本门禁 7 项通过；仓库结构检查确认 3 个工程、77 个声明输入和 5 个共享源，不编译测试或构建文件；Windows PowerShell 5.1 下三个工程的 UTF-8 工程读取检查通过。
- 最终 Inno Setup 7.1.0 安装包从干净暂存目录构建，并在解包后核对 14 个产品文件、三个驱动固定哈希和安装包内容清单。

## 未验证

- 未在本机覆盖安装正式程序；当前 Program Files 仍保留旧版。
- 自动化检查没有真正启动浏览器；验证的是按钮文案、后端动作接线和安装包资产 URL 解析。
- 未覆盖 Windows 主题运行中切换事件；窗口应用新状态或重新打开时会重新读取系统主题。
- 未重复人工关屏、驱动和输入恢复矩阵，因为相关运行代码未修改。
- 实际界面截图来自最终源码的隔离 WPF 文件与假回调；没有调用 APPLY、真实显示准备或正式设置写入，不能代替安装后正式程序验收。
- 应用和安装器没有购买代码签名证书。

## English

Version 0.2.4 recalibrates the Settings glass material against the Pane reference package and verifies it with live desktop Light and Dark captures. Drivers, display preparation, display-off, input recovery, playback protection, hotkeys and user-data formats are unchanged.

The main app and separate WPF Settings app build on .NET Framework 4.8 / C# 5. Sixty-seven isolated Chinese and English WPF checks cover System / Light / Dark, Pane control fills, four-stop highlight edges, readable-surface fallback, legacy theme migration, the fixed footer, compact layout, update labels and removal of the geometry wallpaper. Live desktop captures at the current DPI were compared with Pane's fixed authorized screenshot. WPF lacks Pane's HostBackdrop, so the roughly 98% readable surface and highlight edge are a platform fallback, not a claim of pixel-identical native composition. Twenty-five update parser and installer-asset checks cover `0.2.3 → 0.2.4`, exact Setup naming, case-sensitive release tags, repository URL validation and rejection of untrusted URLs. Seven installer gate cases, repository layout and Windows PowerShell 5.1 build encoding passed. The final Inno Setup 7.1.0 package was built from a clean stage and its 14 product files and pinned driver hashes were verified after extraction.

The installed application was not overwritten. The live images use the final isolated WPF source with fake callbacks; they did not invoke APPLY, real display preparation or formal Settings writes. Automated checks did not launch a browser; they verified button state, backend wiring and installer asset parsing. A live Windows theme-change event is not wired; applying new state or reopening Settings re-reads the system theme. Hardware display-off, driver and input-recovery matrices were not repeated because runtime code did not change. The application and installer remain unsigned.

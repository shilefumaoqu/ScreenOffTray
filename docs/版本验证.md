# 0.2.1 验证范围 / Validation scope

本版只修改设置外观与安装向导视觉，驱动、显示准备、关屏、输入恢复和播放判断沿用 `0.2.0`。完整记录见 [0.2.1 中性玻璃与安装器](0.2.1-中性玻璃与安装器.md)。

## 已完成

- 删除彩色几何壁纸、外围演示底图、外边距和投影；设置窗口只保留自身圆角磨砂玻璃边界。
- 顶层窗口、侧栏和页脚使用不透明雾面材质，隔离截图未再出现透明窗口内容重影。
- 隔离 WPF 布局 39 项通过、0 失败，覆盖中英文、十项名单、宽窄工作区、固定底栏、键盘可见性、背景删除、不透明页脚与三套主题实际颜色差异。
- 浅色、暖白、黑色三套截图均来自隔离假数据，不包含正式设置或个人程序路径。
- Inno Setup 7.1.0 编译通过；动态浅/深色背景、侧图、小图和 Pane 风格字段被编译器接受。
- 更新版本解析 13 项通过；安装器版本门禁 4 项通过，`0.2.1` 高于 `0.2.0`。

## 未验证

- 未覆盖安装当前正式程序。
- 未重复端到端人工关屏、驱动和输入恢复矩阵，因为相关代码未修改。
- 安装器实际运行截图未纳入证据：当前电脑工具启动预览程序时审批超时。
- 干净 Windows 安装、全部 DPI/多屏硬件和长期稳定性仍不等同于本批隔离检查。

## English

This release changes Settings and Setup presentation only. Driver, display preparation, display-off, input recovery and playback decisions remain unchanged from `0.2.0`.

The colored geometry wallpaper, display-only backdrop, outer margin and shadow are removed. Opaque misted surfaces are used for the top-level window, sidebar and footer so isolated screenshots no longer show transparent-window content ghosting. Thirty-nine isolated WPF layout checks passed in Chinese and English, with ten allowlist rows, compact and regular layouts, fixed footer, background removal, opaque-footer and distinct appearance-color assertions. Inno Setup 7.1.0 accepted the dynamic light/dark wizard images. Update parsing and numeric installer version gates passed.

The installed application was not overwritten. Hardware display-off, driver and input-recovery matrices were not repeated because their code did not change. A live Setup screenshot is not used as evidence because the local computer-use launch approval timed out. Clean Windows installation, every DPI/multi-display configuration and long-running stability remain outside this visual-release scope.

# ScreenOffTray 0.2.2 · 构建兼容修复

0.2.2 以已发布的 0.2.1 为运行基线，只修复从源码重新打包时的两个兼容问题。驱动、显示准备、关屏、输入恢复、播放保护、设置外观和用户数据格式不在本批修改范围内。

## 修复内容

- 根目录默认入口使用的 Windows PowerShell 5.1 现在显式按 UTF-8 读取三个工程文件，避免中文资源路径受系统 ANSI 代码页影响。
- innounp 解包验证工具固定到 GitHub 附件 ID `695694723`。上游曾在同名 `innounp-2.zip` 地址把 2.71.2 替换为 2.71.3；本版使用已核验的 2.71.3 SHA256 `F8E45C9676BEBC7D7570108AB572673B541FCF7A7D3D24A04319AC6B5315B4E8` 和独立缓存名，并在下载时明确请求二进制。
- 其他构建依赖和三个驱动文件的固定哈希不变；任何哈希不符仍会停止解压和构建。

## 验证

- Windows PowerShell 5.1 / ANSI 936：三个工程的实际读取语句及图标路径通过；修复前可复现乱码路径失败。
- 依赖夹具：二进制请求头、冷下载、有效缓存复用和错误哈希解压阻断通过。
- 冷启动默认入口：干净源码副本、全新依赖缓存、无附加参数，下载三项依赖，完成构建和最终 14 个产品文件解包比对。
- 版本一致性：程序、设置清单、设置窗口、帮助、安装器、构建输出和双语 README 均指向 0.2.2。
- 更新解析：确认 `0.2.1` 能识别 `0.2.2`，`0.2.2` 与自身比较为最新。

## 边界

本轮没有覆盖安装当前正式程序，也没有在一台全新的 Windows 电脑上执行安装。全新缓存构建发生在当前 Windows 环境的隔离目录，不代表第二台机器认证。未重复人工关屏、驱动和输入恢复矩阵，因为相关运行代码未修改。安装包和应用没有购买代码签名证书。

## English

Version 0.2.2 uses the published 0.2.1 as its runtime baseline and fixes two source-build compatibility issues only. Drivers, display preparation, display-off, input recovery, playback protection, Settings appearance and user-data formats are unchanged.

The default root entry now reads project files explicitly as UTF-8 under Windows PowerShell 5.1. The build-only innounp verifier is pinned to GitHub asset ID `695694723`, version 2.71.3, SHA256 `F8E45C9676BEBC7D7570108AB572673B541FCF7A7D3D24A04319AC6B5315B4E8`, a separate cache name and an explicit binary request header. Other dependency and driver pins remain unchanged; a hash mismatch still stops extraction and the build.

Validation covers the actual loader and icon paths under Windows PowerShell 5.1 / ANSI 936, a local fixture for cold downloads and corrupt-hash rejection, a fresh-cache build through the unmodified root entry, a 14-file extracted-payload comparison, release-version consistency and update-version parsing. No installer was run on the current installed program, and no second clean Windows computer was used. Hardware display-off, driver and input-recovery matrices were not repeated because runtime code did not change. The application and installer remain unsigned.

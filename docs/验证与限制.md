# 验证与限制 / Validation and limitations

以下是 0.1.4 在 2026-10-25 已有验证记录的公开摘要。原始个人配置、设备快照、现场日志、代码审查会话和旧版本目录不随项目公开。

## 已有证据

- 自动计时辅助类：97 条虚拟时间断言。
- 隔离输入观察点、计时组合与菜单检查：1,976 条断言；中英文菜单共 48 张离屏渲染，覆盖常用缩放。
- 短暂保亮请求及最终保护通知：75 条增量断言。
- 50 项受保护文件或方法区域比对；既有驱动、输入决策和显示切换方式保留。
- 专门代码审查使用 `codex review`，启动记录确认为 `gpt-6.1-sol / high`。两项独立复核发现已修复，最终无剩余已确认的可操作问题。
- Windows PowerShell 5.1 构建，Inno Setup 7.1.0 打包；解包核对全部 11 项应用载荷，驱动三文件哈希一致。
- 单台电脑完成正常退出旧版、覆盖安装及普通权限启动；原设置逐字节保留。没有在安装中强杀程序、改驱动或关闭其他应用。

这些是不同层次的证据。纯断言和离屏渲染不等于实屏验收；安装成功不等于自然空闲到期、全部播放器兼容或长期运行稳定。

## 尚未完整验证

- 干净 Windows 环境中的首次设备创建、所有提权与取消路径、真实卸载异常路径。
- 多显示器、所有分辨率/缩放/HDR、窗口位置在显示拓扑切换后的全部表现。
- 虚拟屏对混合显卡电脑的自动独显直连切换影响。
- 全部视频/音乐应用的显示请求行为，以及未标记的内核虚拟输入。
- 本版真实自动到期实屏验收、长期运行资源曲线、全部异常恢复竞争场景。

快捷键依赖 Windows 注册与已有输入监听，其他软件拦截或冲突反馈可能存在盲区。注册成功不证明组合键一定能到达本程序；可更换组合键或使用托盘入口。本次 GitHub 发布不更改这部分逻辑。

## English

This is a public summary of existing 0.1.4 verification from 2026-10-25. It covers 97 virtual-time assertions, 1,976 isolated connection/menu assertions, 48 offscreen renders, 75 incremental protection assertions, 50 frozen-input comparisons, dedicated `codex review` with observed `gpt-6.1-sol / high`, independent follow-up review, pinned-tool packaging and verification of all 11 payload files. One computer was upgraded and launched without elevation while preserving settings byte-for-byte and reusing its driver.

These results support their stated scopes. They do not prove clean-system first installation, all UAC/uninstall failure paths, all display configurations, hybrid-GPU display switching, every media application's display requests, unmarked virtual input, real automatic expiry in this build, or long-term stability. The accepted physical screen-off matrix was not repeated. Shortcut registration and feedback have known blind spots.

The installer is 3,068,863 bytes; its application payload is 607,939 bytes. Payload size excludes the generated uninstaller and runtime files. CPU, memory, handles, threads and long-term I/O were not measured again for this publication.

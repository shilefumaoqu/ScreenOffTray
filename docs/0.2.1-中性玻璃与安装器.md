# ScreenOffTray 0.2.1 · 中性玻璃与安装器

## 范围

以公开发布的 `0.2.0` 为基线，独立发布 `0.2.1`，不覆盖旧 Release。驱动、显示准备、关屏、输入恢复和播放保护判断不在本批修改范围内。

## 设置界面

- 删除参考样板中的橙、蓝、绿、黄几何壁纸。
- 删除窗口外围的演示底图、24px 外边距和投影；窗口边界改为磨砂玻璃主体自身的圆角透明边。
- 顶层窗口、侧栏和页脚改为不透明雾面材质，避免透明窗口合成产生内容重影；卡片保留内部层次。
- 浅色改为中性蓝灰材质；暖白使用独立暖灰不透明材质，黑色保持深色材质，内部主题值继续兼容 `geometry`、`warm`、`black`。
- 左上仅显示双层月亮图标与 `ScreenOffTray`，不显示“设置”副标题。
- 左下仅保留状态点和“检查”。
- 双语、键盘操作、固定底栏、窄窗滚动和设置事务保持原样。

## 安装向导

- 固定使用 Inno Setup 7.1.0。
- `WizardStyle=modern dynamic polar hidebevels`，跟随系统浅色/深色外观。
- 浅色和深色分别使用中性雾面背景，玻璃卡片、柔和蓝灰光晕、细高光边与同款双层月亮标识。
- 使用原生向导文字、按钮、键盘、高 DPI、升级核验和卸载流程；未伪造实时桌面模糊。
- 新增可重复生成向导素材的脚本 `Installer/generate-wizard-assets.ps1`。

## 验证

- WPF 隔离布局：39 项通过，0 失败；覆盖中英文、十项名单、宽窄工作区、固定底栏、键盘可见性、外层展示背景删除、页脚不透明材质和三套主题顶层颜色差异。
- 实际查看浅色/深色背景、侧图和小图素材。
- Inno Setup 7.1.0 编译通过，动态向导和全部图片字段被编译器接受。
- 版本门禁：4 项静态比较通过，拒绝高于 `0.2.1.0` 的旧升级路径。
- 更新版本解析：13 项通过，确认 `0.2.1` 高于 `0.2.0`。

## 边界

- 隔离测试不修改正式设置、显示设备或驱动。
- 未覆盖安装当前正式程序；安装包与 GitHub Release 单独发布。
- 未重复已经通过的实体关屏、输入恢复和驱动矩阵，因为这些代码未改。
- 安装器图片已编译，但受当前电脑工具启动审批超时影响，未把实际向导运行截图作为交付证据。

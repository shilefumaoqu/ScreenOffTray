# ScreenOffTray 0.2.0 · Pane 界面接入与发布

## 交付范围

- 版本升级为 `0.2.0`，设置界面作为独立的 `ScreenOffTray.Settings.exe` 运行。
- 界面采用已确认的 Pane 风格三页结构：通用、播放保护、关于。
- 提供几何、暖白、黑色三种外观，默认几何；主题随其他设置一起保存。
- 左上角只显示应用图标和 `ScreenOffTray`，左侧底部只显示状态点、状态文字和“检查”。
- 移除小猫；图标来自用户确认的参考图片，打包时只裁切和缩放，不重绘。
- 保留托盘、快捷键、显示准备、关屏、实体输入恢复、播放保护、白名单和开机启动流程。
- 驱动文件、显示切换恢复逻辑和已经验收的关屏输入规则未在本批重写。

## 接入方式

后台仍负责全部状态和写入。设置界面通过当前用户的本地命名管道读取带版本的状态快照，并提交保存、白名单、准备、复检和更新命令。界面进程不能直接改驱动、显示设备、快捷键注册或正式设置。

读取部分包含：

- 显示就绪、检查、准备和诊断状态。
- 当前播放来源、白名单、保护上限和播放保护说明。
- 已生效设置、迁移选项、保存中状态和更新状态。

设置窗口关闭后进程结束，后台继续运行。设置存活期间继续遵守原编辑门禁；连接断开时不自动重发写命令。

## 验证结果

- 主程序 Release 编译通过。
- `ScreenOffTray.Settings` Release 编译通过。
- IPC 定向测试通过，覆盖重复请求、迟到结果、断线重连、正常退出和不允许重复写入。
- 消息协议测试通过，覆盖主题字段。
- 更新版本比较测试通过，确认 `0.2.0` 高于 `0.1.9.13`，且不会误判更高版本。
- 安装器版本门禁静态测试通过。
- 私有非输入桌面中的假后台测试通过，覆盖十项白名单、真实本地图标读取、保存和正常退出。
- 中文、英文和三种外观已生成隔离截图，检查了三页导航、动态播放行、白名单、保护上限和固定底栏。
- 设置 UI 生命周期测试通过，覆盖无效连接、连接前退出、错误对话框和后台退出。
- 33 项中英文界面回归通过，覆盖未加入白名单、真实播放保护、手动暂停、保护上限、紧凑侧栏和极小工作区控件可达性。
- 专门代码审查使用 `gpt-6.1-sol / high`。首轮及定向复核发现四项 P2：空白名单提示失真、极小工作区窗口越界、手动暂停误报、紧凑侧栏遮挡控件；均已完成修复和回归。最终定向复核未发现可确认缺陷。

隔离启动测试使用假后台和私有非输入桌面。默认 WPF 渲染路径下测得冷启动约 `1.19～2.05` 秒，短暂连续启动约 `1.07～1.60` 秒；机器负载会使数值波动。该数据不是正式安装后的实际桌面体感，也不代表 DWM 帧时间。设置进程关闭后不常驻，因此没有用隐藏预热进程换取表面启动速度。

## 未验证边界

- 本轮未覆盖安装当前正式版本，也未替换本机已安装程序。
- 未在干净 Windows 系统上执行完整安装。
- 未重复人工测试实体切屏和恢复矩阵，因为相关驱动与显示切换逻辑未在本批重写。
- 未测量真实鼠标拖动期间的 DWM 帧时间；已完成的验证只使用隔离窗口消息和离屏渲染。
- GitHub 新版本发布不等同于本机安装验收。

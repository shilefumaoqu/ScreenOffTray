# 目录结构

| 目录 | 用途 |
| --- | --- |
| `src/ScreenOffTray` | 常驻托盘、设置保存、显示准备、播放保护和关屏会话 |
| `src/ScreenOffTray.Settings` | 按需启动的 WPF 设置程序及自身图标缓存 |
| `src/ScreenOffTray.DriverSetup` | 安装/卸载与只读核验助手 |
| `src/Shared` | 被多个工程实际编译的共用源码，不生成额外 DLL |
| `Installer` | Inno Setup 向导、向导素材及构建脚本 |
| `resources` | 程序图标、帮助、默认设置说明 |
| `vendor` | 固定版本第三方驱动与许可证 |
| `tests` | 当前测试、隔离工具与[入口说明](../tests/README.md) |
| `docs` | 使用、构建、版本验证和展示素材 |

根目录保留双语 README、发布说明、许可证、Git 规则及 `打包安装版.cmd`。

构建入口保持不变：`打包安装版.cmd`。如需独立验证输出，在仓库根目录运行：

```powershell
.\Installer\build.ps1 -OutputDirectory .\checks\layout-build
```

源码路径调整不改变安装后的文件结构、设置路径、程序集名称、版本号或驱动材料。三个工程都显式声明源码和资源，打包器按各工程所在目录解析相对路径后复制到干净暂存目录，再构建并核对最终安装包解包清单。

旧 WinForms 设置界面及专用测试已移出当前树，历史 Tag 保留原始版本。带版本号的文档是当时的记录，其中历史命令与路径需在对应版本使用；当前构建和测试以[构建与验证](构建与验证.md)及 `tests/README.md` 为准。

本轮只整理目录和引用。常驻程序、WPF 和助手的 C#、XAML、配置、图标与驱动内容沿用基线；目录整理本身不构成内存或速度收益证明。

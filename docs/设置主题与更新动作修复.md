# 0.2.4 设置主题与更新入口

主题为跟随系统、浅色、深色。参考手册的几何、暖白等测试背景不进入产品主题。旧 geometry、warm 映射浅色，旧 black 映射深色，兼容现有设置。

设置窗口接入原生 Desktop Acrylic，保留 Pane 的控件填充、文字层级、雾蓝强调与四段高光。饱和度、着色与模糊由 Windows 提供，不声称参数或像素完全相同。原候选的约 98% 实色表面没有实现背景模糊，不能算玻璃通过；本版已用同一窗口的外部双背景实拍复验，见[原生玻璃验证](原生玻璃验证.md)。

原生材质不可用、高对比度或透明效果关闭时使用实色回退。DPI 后的区域重建延迟到 WPF 完成尺寸调整后，关闭时解除回调。系统主题变化会重新读取外观，跟随系统的保存值仍为 system。

更新入口沿用 0.2.3 的安全规则：发现稳定版本后，按钮明确变为“下载安装包”。只接受同一仓库、大小写精确的 Release Tag、精确 Setup 文件名和可信 URL；无合适资产时打开对应 Release 页面。不自动运行 Setup、退出或覆盖程序，浏览器启动失败会显示错误。

隔离测试覆盖主题兼容、原生材质附件/回退、DPI 时序、更新文案和 URL 解析。真实更新及下载在发布后另行回验，未执行真实安装。

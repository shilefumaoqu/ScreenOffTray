# 构建与验证 / Build and verification

Windows x64需要.NET Framework4.8。根目录运行：

```powershell
.\打包安装版.cmd
```

构建器下载并核验固定版本的参考程序集、Inno Setup7.1.0与解包工具；源码复制到干净暂存目录构建，安装包输出到安装包目录。构建不会安装驱动或启动主程序。离线指最终安装包可离线安装，首次构建仍需下载工具。

仅编译隔离UI（不启动正式程序，不修改显示设备）：

```powershell
.\tests\CSettingsUiTests.ps1 -CompileOnly
```

其他测试入口位于tests，执行前阅读源码与[版本验证](版本验证.md)。测试可创建私有非输入桌面与短期测试子进程，超时只结束其持有句柄的测试进程，不操作其他软件。当前安装包SHA256由Release附件给出；没有PDB或个人配置。

## English

On Windows x64 with .NET Framework4.8, run the root `打包安装版.cmd`. The builder verifies pinned reference assemblies, Inno Setup7.1.0 and unpacking tools, builds from clean staged sources and verifies extracted contents. It does not install the product or driver. First-time building needs network access; the resulting installer works offline.

Run `tests\CSettingsUiTests.ps1 -CompileOnly` to compile the isolated UI harness without starting the product. Read test sources and validation limits before execution. Real hardware and long-term validation are separate.

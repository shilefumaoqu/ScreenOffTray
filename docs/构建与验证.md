# 构建与验证 / Build and verification

Windows x64需要.NET Framework4.8。根目录运行：

```powershell
.\打包安装版.cmd
```

构建器下载并核验固定版本的参考程序集、Inno Setup7.1.0与解包工具；源码复制到干净暂存目录构建，安装包输出到安装包目录。构建不会安装驱动或启动主程序。离线指最终安装包可离线安装，首次构建仍需下载工具。

根入口使用 Windows PowerShell 5.1；构建器显式按 UTF-8 读取工程文件，避免中文资源路径被系统 ANSI 编码误读。只在 PowerShell 7 下运行构建不能替代此入口的兼容验证。编码回归检查：

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File tests/BuildEncodingTests.ps1
```

仅编译隔离UI（不启动正式程序，不修改显示设备）：

```powershell
.\tests\WpfSettingsProbe.ps1 -CompileOnly
```

其他测试入口位于tests，执行前阅读源码与[版本验证](版本验证.md)。测试可创建私有非输入桌面与短期测试子进程，超时只结束其持有句柄的测试进程，不操作其他软件。当前安装包SHA256由Release附件给出；没有PDB或个人配置。

## English

On Windows x64 with .NET Framework4.8, run the root `打包安装版.cmd`. The builder verifies pinned reference assemblies, Inno Setup7.1.0 and unpacking tools, builds from clean staged sources and verifies extracted contents. It does not install the product or driver. First-time building needs network access; the resulting installer works offline.

Run `tests\WpfSettingsProbe.ps1 -CompileOnly` to compile the isolated UI harness without starting the product. Read test sources and validation limits before execution. Real hardware and long-term validation are separate.

当前源码归属见[目录结构](目录结构.md)，测试入口见[测试说明](../tests/README.md)。历史版本文档中的旧路径适用于对应 Tag。

原工具缓存不在默认目录时，可通过 `Installer/build.ps1 -ToolsRoot <缓存目录> -OutputDirectory <验证输出目录>` 指定；WPF 测试可用 `-ReferenceRoot <net48/build目录>` 指向同一固定参考程序集。
